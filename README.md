# Power BI Dashboards

A repository containing Power BI dashboards (.pbix), lightweight data dictionaries, and links to live demos. Designed to be professional and presentable to HR teams and non-technical readers.

## Overview

This project includes:
- Power BI Desktop files for each dashboard
- Simple data dictionaries and model notes
- Links to live demos or hosted previews
- Brief usage notes and data privacy considerations

## How to View Demos

### Local (Power BI Desktop)
1. Install Power BI Desktop.
2. Open the corresponding `.pbix` file from the `dashboards/` directory.
3. Refresh data if needed and review visuals, slicers, and pages.

### Online Demos
- Open the Demo Link listed in the Demo Links section.
- If access is gated, follow the required steps (workspace access, permissions, or public access).
